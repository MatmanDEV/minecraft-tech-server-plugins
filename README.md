# Tech Server Plugins

Custom plugins developed for my Minecraft 1.21.1 progression server.

## Plugins

- TechProgression
- TechSell

## Server Features

- Technology progression
- Locked crafting
- Locked workstations
- Economy progression
- Sell-only economy
- End Research system
- DeluxeMenus integration
- LuckPerms integration
- TAB integration

## Gameplay Loop

Gather Resources
↓
Sell Resources
↓
Earn Money
↓
Research Technologies
↓
Unlock Better Equipment
↓
Access Better Resources
↓
Complete End Research
↓
Craft Eyes of Ender
↓
Defeat the Ender Dragon
